## 💻 Running the Code

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/fcc.bootcamp.git
```

Navigate into the repository:

```bash
cd fcc.bootcamp
```

JavaScript files can be run using Node.js:

```bash
node filename.js
```
